\chapter{Herramientas, requerimientos de software y arquitectura}
\label{chp:4}


Para cumplir el requerimiento de software libre, el cuadro~\ref{tab:software} muestra todos los programas utilizados durante el proyecto con su respectiva descripción de uso y la licencia de dicho software, para esto último se toma en cuenta la definición de \ac{FLOSS} para incluir software que es abierto y libre dada por la \ac{FSF}\cite{gnu_free_sw}. El único programa utilizado que no es \acs{FLOSS} es GitHub, utilizado para el hosting del código y la colaboración entre los miembros del grupo, sin embargo, el proyecto no posee \textit{vendor lock-in}, por lo tanto, se puede (y se recomienda) migrar todo a una instancia de Gitea\cite{gitea_about} con infraestructura propia y así el proyecto sea 100\% software libre y abierto.
